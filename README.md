# Ejercicios y Prácticas - ConquerBlocks

Repositorio oficial de mi trayectoria de aprendizaje y desarrollo en el programa Full-Stack de **ConquerBlocks**. Aquí agrupo de forma cronológica los módulos, laboratorios y prácticas de código.

## 📂 Estructura del Repositorio

* **`01-python-consola/`** - Scripts lógicos y utilidades ejecutadas desde la terminal (generadores, conversores, etc.).
* **`02-python-tkinter/`** - Aplicaciones de escritorio con interfaz gráfica de usuario.
* **`03-sql/`** - Consultas, esquemas y bases de datos.
* **`04-html/`** - Estructuras base y prácticas de maquetación web.
* **`05-css/`** - Estilos, clases, layouts (Grid/Flexbox) y diseño visual.
